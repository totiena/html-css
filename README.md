# 🌐 Шпаргалка юного веб-мастера

Интерактивная шпаргалка по **HTML и CSS** для тех, кто только начинает делать сайты. Здесь есть всё, что нужно от первого тега до публикации своего сайта в интернете.

👉 **Открыть сайт:** https://totiena.github.io/html-css/

## Что внутри

В каждой теме есть объяснение простыми словами, готовый код с кнопкой «Копировать» и блок **«Попробуй сам»**. В нём можно двигать ползунки, нажимать кнопки или менять код и сразу видеть результат. Есть мини-тесты «Проверь себя».

| Раздел | Темы |
| --- | --- |
| 🧰 Подготовка | где писать код, как безопасно установить редактор, как сохранять файлы и картинки |
| 📄 HTML | каркас страницы, текст, картинки, ссылки и якоря, таблицы, списки, формы |
| 🎨 CSS | подключение CSS-файла, селекторы, цвет и шрифт, рамки, отступы, маркеры списков |
| 📐 Разметка | контейнеры и `display`, Flexbox, виды позиционирования |
| ✨ Эффекты | псевдоклассы, псевдоэлементы, градиенты, тени `box-shadow`, трансформации, видео и аудио |
| 🚀 Публикация | пошаговая инструкция для GitHub Pages, другие хостинги, частые ошибки |

## Файлы

| Файл | Что это |
| --- | --- |
| `index.html` | сама страница |
| `style.css` | оформление |
| `script.js` | интерактивные примеры |
| `star.svg` | картинка для примеров |

Сайт работает без установки: достаточно открыть `index.html` в браузере.
