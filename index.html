Что такое HTML и CSS

Любой сайт — это обычные текстовые файлы. Браузер читает их и превращает в красивую страницу. Для этого есть два языка: HTML говорит, что есть на странице, а CSS — как это выглядит.

HTML — язык гипертекстовой разметки

HHyperгипер-, сверх-
TTextтекст
MMarkupразметка
LLanguageязык
  • Гипертекст — это текст со ссылками, по которым можно «прыгать» с места на место и с сайта на сайт. Обычная книга читается по порядку, а гипертекст — как захочешь.
  • Разметка — это пометки, которые объясняют браузеру, что где: «это заголовок», «это абзац», «это картинка». Как учитель, который подчёркивает и подписывает части текста на полях. Такие пометки называются теги.

CSS — каскадные таблицы стилей

CCascadingкаскадные
SStyleстилей
SSheetsтаблицы, листы
  • Стиль — это внешний вид: цвет, шрифт, размер, рамки, расположение.
  • Каскад — это водопад, который падает ступеньками. Стили тоже «стекают» сверху вниз: от коробки — ко всему, что внутри неё. А если для одного элемента написано несколько правил, побеждает более точное или то, что написано ниже.

📄 HTML — скелет

Из чего сделана страница: заголовки, текст, картинки, ссылки, таблицы.

🎨 CSS — одежда

Как всё выглядит: цвета, шрифты, рамки, где что стоит на странице.

Код — это английские слова

Весь HTML и CSS построен на английских словах и их сокращениях. <p> — это paragraph, абзац. <img> — image, картинка. color — цвет. Знаешь слова — понимаешь код, и его не нужно зубрить: достаточно помнить перевод.

Поэтому на этом сайте в каждом разделе есть 📖 словарик с полным названием и переводом всех слов. А слова в коде, подчёркнутые пунктиром, можно навести мышкой или нажать пальцем — появится перевод.

Для сайта нужны два файла

📄 index.html

Что есть на странице: заголовки, текст, картинки, ссылки. Пишется на языке HTML. Это главная страница — именно её браузер открывает первой.

🎨 style.css

Как это выглядит: цвета, шрифты, рамки, расположение. Пишется на языке CSS. Один файл стилей может оформлять сразу много страниц.

Представь человека: index.html — это он сам, а style.css — его одежда. Файлы связаны одной строчкой в index.html — о ней в разделе «Каркас страницы». Картинки лежат рядом, обычно в папке img.

📁 my-site
📄 index.html ← содержимое страницы
🎨 style.css ← оформление
📁 img ← картинки

Куда и как сохранять файлы

  1. Заведи папку для сайта, например на Рабочем столе: my-site. Все файлы сайта — страницы, CSS, картинки — клади только в неё.
  2. Главную страницу назови index.html, стили — style.css.
  3. Названия файлов пиши латиницей, маленькими буквами и без пробелов: my-cat.jpg, а не Мой Кот.jpg.
  4. В VS Code открывай всю папку сразу: Файл → Открыть папку. Слева появятся все файлы сайта.
  5. Чтобы посмотреть сайт, дважды нажми на index.html — он откроется в браузере.
⚠️ Если пишешь в Блокноте: при сохранении выбери «Тип файла: Все файлы» и «Кодировка: UTF-8». Иначе файл сохранится как index.html.txt, а русские буквы превратятся в непонятные значки.
💡 Чтобы видеть окончания файлов (.html, .txt, .jpg), включи их в Windows: Проводник → Вид → Показать → Расширения имён файлов.

Картинки: храним у себя

Картинку можно вставить двумя способами: ссылкой на чужой сайт или своей копией, которая лежит в папке сайта. Надёжнее — своя копия.

🔗 По ссылке из интернета

  • Хозяин сайта удалит или переименует картинку — у тебя она пропадёт.
  • Некоторые сайты запрещают показывать свои картинки на других сайтах.
  • Длинную ссылку легко написать с ошибкой.

📁 Своя копия в папке сайта

  • Картинка всегда на месте: ты сам решаешь, когда её удалить.
  • Загружается на GitHub вместе с остальными файлами сайта.
  • Короткий путь, в котором трудно ошибиться.

Вот что видят посетители, когда картинка по ссылке пропала:

💡 Поэтому всегда пиши alt — описание картинки. Если она не загрузится, человек хотя бы прочитает, что там было.

Как сохранить картинку к себе

  1. Найди картинку и нажми на неё правой кнопкой мыши → «Сохранить картинку как…».
  2. Выбери папку своего сайта. Удобно сделать в ней отдельную папку img для всех картинок.
  3. Переименуй файл: латиница, маленькие буквы, без пробелов — cat.jpg. Окончание .jpg или .png не трогай.
  4. Напиши в коде путь к картинке — какой именно, смотри ниже.
  5. При публикации на GitHub загрузи картинки (или всю папку img) вместе с остальными файлами.

HTML — это теги в угловых скобках. Почти у каждого тега есть открывающая и закрывающая часть: <p> … </p>. Между ними — содержимое.

Что лежит в <head> и зачем

<head> — служебная часть страницы. На самом сайте её не видно, но без неё сайт работает плохо: ломаются буквы, пропадают стили, на телефоне всё становится крошечным.

СтрочкаЗачем нужна
<meta charset="UTF-8">Говорит браузеру, как читать буквы. Без неё русский текст может превратиться в непонятные значки
<meta name="viewport" content="width=device-width, initial-scale=1">Нужна для телефонов: без неё сайт на телефоне показывается мелко, как на большом экране
<title>…</title>Название сайта на вкладке браузера и в закладках
<link rel="stylesheet" href="style.css">Подключает файл со стилями. Без неё страница будет без цветов и оформления

Списки

Неупорядоченный <ul>

Порядок не важен: список покупок, любимые игры. У пунктов точки.

Порядок важен: шаги инструкции, рейтинг. У пунктов номера.

Куда уходят данные из формы?

⚠️ Пока — никуда. Сама по себе HTML-форма ничего не хранит и никуда не отправляет. Человек нажмёт «Отправить», страница перезагрузится, и всё, что он написал, пропадёт. Тебе ничего не придёт.

Чтобы ответы сохранялись, нужен сервер — компьютер, который примет данные и запишет их. У сайта на GitHub Pages своего сервера нет, поэтому многие пользуются бесплатными сервисами, которые принимают формы.

Способ 1. Google Формы — проще всего

Форму делаешь не кодом, а в конструкторе Google, а потом вставляешь её на свой сайт. Ответы собираются в Google Форме и в Google Таблице.

  1. Вместе со взрослым открой forms.google.com и создай форму с вопросами.
  2. Нажми «Опубликовать» справа вверху. Неопубликованная форма ответы не принимает.
  3. Нажми на три точки ⋮ рядом → «Встроить HTML» (Embed HTML) → «Копировать».
  4. Вставь скопированный код в свой index.html — туда, где должна быть форма:
  5. Ответы смотри в форме на вкладке «Ответы». Оттуда же их можно открыть в Google Таблице.

Минус: оформить такую форму своим CSS не получится — она выглядит как Google Форма.

Способ 2. Своя форма + Formspree

Форму пишешь сам, на HTML и CSS, как в примерах выше. А принимает ответы сервис Formspree и пересылает их тебе на почту. Бесплатно — до 50 ответов в месяц.

  1. Вместе со взрослым зарегистрируйся на formspree.io и создай форму (New Form). Сервис даст адрес вида https://formspree.io/f/abcdwxyz.
  2. Впиши этот адрес в action, а в method — POST.
  3. Проверь, что у каждого поля есть name.
АтрибутЧто значит
actionКуда отправить данные — адрес сервиса
method="POST"Как отправить: «спрятать в конверт», чтобы данные не попали в адресную строку
nameПодпись поля. По ней ты поймёшь, где в письме имя, а где сообщение
⚠️ Про безопасность. Не проси в форме адрес, телефон, пароли и другие личные данные. Для отзывов и вопросов хватит имени и сообщения. А все регистрации в сервисах — только вместе со взрослым.

HTML говорит, что есть на странице. CSS говорит, как это выглядит. Все стили пишем в файле style.css, который подключили в <head> (как это сделать — в разделе «Каркас страницы»). Теги <style> в файле style.css не нужны.

СелекторКого выбираетВ HTML

.cardВсех, у кого такой класс (точка!)<div class="card">
#logoОдного, у кого такой id (решётка!)<img id="logo">
header pАбзацы, которые лежат внутри шапки<header><p>

Градиенты и тени

Градиент — это плавный переход одного цвета в другой. Для CSS градиент — это картинка, поэтому его пишут в background-image или в background, но не в background-color.

ВидКак пишетсяКак выглядит
Слева направоbackground-image: linear-gradient(to right, green, red);
Под угломbackground-image: linear-gradient(45deg, pink, purple);
Много цветовbackground-image: linear-gradient(to right, red, orange, yellow, green, blue);
Чёткие полосы (флаг)background-image: linear-gradient(white 33%, blue 33% 66%, red 66%);
Круг от центраbackground-image: radial-gradient(circle, white, blue);
Овал (эллипс)background-image: radial-gradient(yellow, orange, red);
Круг из углаbackground-image: radial-gradient(circle at top left, gold, navy);
По кругуbackground-image: conic-gradient(red, yellow, lime, aqua, blue, magenta, red);
Круговая диаграммаbackground-image: conic-gradient(tomato 0 25%, gold 25% 60%, skyblue 60%);
Косые полоскиbackground-image: repeating-linear-gradient(45deg, black 0 10px, yellow 10px 20px);
Мишеньbackground-image: repeating-radial-gradient(circle, white 0 10px, pink 10px 20px);
💡 background-image и background здесь работают одинаково. Разница: background — «общее» свойство, оно заменяет сразу и цвет, и картинку фона. background-image меняет только картинку.

Куда направить градиент

to bottom right↘ в правый нижний угол
45deg↗ по диагонали, угол в градусах

В градусах: 0deg — вверх, 90deg — вправо, 180deg — вниз, 270deg — влево.
