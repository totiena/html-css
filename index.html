Куда и как сохранять файлы

  1. Заведи папку для сайта, например на Рабочем столе: my-site. Все файлы сайта — страницы, CSS, картинки — клади только в неё.
  2. Главную страницу назови index.html, стили — style.css.
  3. Названия файлов пиши латиницей, маленькими буквами и без пробелов: my-cat.jpg, а не Мой Кот.jpg.
  4. В VS Code открывай всю папку сразу: Файл → Открыть папку. Слева появятся все файлы сайта.
  5. Чтобы посмотреть сайт, дважды нажми на index.html — он откроется в браузере.
⚠️ Если пишешь в Блокноте: при сохранении выбери «Тип файла: Все файлы» и «Кодировка: UTF-8». Иначе файл сохранится как index.html.txt, а русские буквы превратятся в непонятные значки.
💡 Чтобы видеть окончания файлов (.html, .txt, .jpg), включи их в Windows: Проводник → Вид → Показать → Расширения имён файлов.

Картинки: храним у себя

Картинку можно вставить двумя способами: ссылкой на чужой сайт или своей копией, которая лежит в папке сайта. Надёжнее — своя копия.

🔗 По ссылке из интернета

  • Хозяин сайта удалит или переименует картинку — у тебя она пропадёт.
  • Некоторые сайты запрещают показывать свои картинки на других сайтах.
  • Длинную ссылку легко написать с ошибкой.

📁 Своя копия в папке сайта

  • Картинка всегда на месте: ты сам решаешь, когда её удалить.
  • Загружается на GitHub вместе с остальными файлами сайта.
  • Короткий путь, в котором трудно ошибиться.

Вот что видят посетители, когда картинка по ссылке пропала:

💡 Поэтому всегда пиши alt — описание картинки. Если она не загрузится, человек хотя бы прочитает, что там было.

Как сохранить картинку к себе

  1. Найди картинку и нажми на неё правой кнопкой мыши → «Сохранить картинку как…».
  2. Выбери папку своего сайта. Удобно сделать в ней отдельную папку img для всех картинок.
  3. Переименуй файл: латиница, маленькие буквы, без пробелов — cat.jpg. Окончание .jpg или .png не трогай.
  4. Напиши в коде путь к картинке — какой именно, смотри ниже.
  5. При публикации на GitHub загрузи картинки (или всю папку img) вместе с остальными файлами.

Текст, картинки и ссылки

ТегЧто делает
<h1>…</h1>Самый главный заголовок. Есть от h1 (крупный) до h6 (мелкий)
<p>…</p>Абзац

⚠️ Частая ошибка: картинка пишется <img src="…">, а не <src img="…">. Сначала название тега, потом его настройки.

Ссылка на часть страницы (якорь)

Можно сделать ссылку не на другой сайт, а на место на этой же странице. Для этого:

  1. Дай нужному месту имя через id: <section id="tables">
  2. В ссылке напиши это имя с решёткой: <a href="#tables">

HTML

Списки

Неупорядоченный <ul>

Порядок не важен: список покупок, любимые игры. У пунктов точки.

Упорядоченный <ol>

Порядок важен: шаги инструкции, рейтинг. У пунктов номера.

Каждый пункт в обоих списках — это <li> (list item). Вложенный список кладётся внутрь <li>, до его закрывающего тега.

Псевдоэлементы

Псевдоэлемент красит часть элемента (первую букву, первую строку) или добавляет в него то, чего нет в HTML. Пишется через два двоеточия: h2::before.

ПсевдоэлементЧто делает
::beforeДобавляет что-то перед содержимым
::afterДобавляет что-то после содержимого
::first-letterПервая буква
::first-lineПервая строчка
::selectionТекст, который выделили мышкой
::placeholderСерая подсказка в пустом поле
⚠️ У ::before и ::after обязательно должно быть свойство content. Без него они не появятся. Если текст не нужен, пишут пустые кавычки: content: "";

Градиенты и тени

Градиент — это плавный переход одного цвета в другой. Для CSS градиент — это картинка, поэтому его пишут в background-image или в background, но не в background-color.

ВидКак пишетсяКак выглядит
Слева направоbackground-image: linear-gradient(to right, green, red);
Под угломbackground-image: linear-gradient(45deg, pink, purple);
Много цветовbackground-image: linear-gradient(to right, red, orange, yellow, green, blue);
Чёткие полосы (флаг)background-image: linear-gradient(white 33%, blue 33% 66%, red 66%);
Круг от центраbackground-image: radial-gradient(circle, white, blue);
Овал (эллипс)background-image: radial-gradient(yellow, orange, red);
Круг из углаbackground-image: radial-gradient(circle at top left, gold, navy);
По кругуbackground-image: conic-gradient(red, yellow, lime, aqua, blue, magenta, red);
Круговая диаграммаbackground-image: conic-gradient(tomato 0 25%, gold 25% 60%, skyblue 60%);
Косые полоскиbackground-image: repeating-linear-gradient(45deg, black 0 10px, yellow 10px 20px);
Мишеньbackground-image: repeating-radial-gradient(circle, white 0 10px, pink 10px 20px);
💡 background-image и background здесь работают одинаково. Разница: background — «общее» свойство, оно заменяет сразу и цвет, и картинку фона. background-image меняет только картинку.

В градусах: 0deg — вверх, 90deg — вправо, 180deg — вниз, 270deg — влево.

Шаги публикации

Как исправить что-то на сайте

Снова Add file → Upload files, загрузи исправленный файл с тем же именем и нажми Commit changes. Через пару минут сайт обновится. Не видишь изменений — нажми Ctrl + F5.

Если что-то не работает

Что случилосьПочему и что делать

Нет картинокКартинки не загрузили или в src путь к твоему компьютеру

Другие хостинги

Хостинг — это компьютер в интернете, который всё время включён и показывает твой сайт всем. GitHub Pages — не единственный. Вот ещё два бесплатных, куда подходят те же файлы index.html и style.css.

🐱

Neocities

Сайт для тех, кто делает личные страницы своими руками. Код можно писать прямо в браузере, ничего не устанавливая, а ещё смотреть сайты других людей и вдохновляться.

Адрес: твоё-имя.neocities.org

  1. Зайди на neocities.org и нажми Create my site.
  2. Придумай имя сайта латиницей, пароль, укажи почту.
  3. В разделе Dashboard перетащи свои файлы в окно загрузки.
  4. Чтобы исправить файл, нажми на него — откроется редактор кода.
📦

Netlify Drop

Самый быстрый способ: просто перетащи папку с сайтом на страницу — и через несколько секунд получишь ссылку.

Адрес: название.netlify.app

  1. Открой app.netlify.com/drop.
  2. Перетащи папку с сайтом в пунктирное окошко.
  3. Сайт сразу появится, но будет закрыт временным паролем.
  4. Чтобы сайт остался и открывался для всех, войди в аккаунт и «забери» его (claim).
